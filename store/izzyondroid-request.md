Title: Inclusion request: VidStash (com.mudassir.vidstash)

**App:** VidStash
**Package:** com.mudassir.vidstash
**Source:** https://github.com/mmudassir0/VidStash
**Licence:** GPL-3.0-only
**APK:** attached to every GitHub release (`VidStash.apk`, latest: https://github.com/mmudassir0/VidStash/releases/latest), about 11 MB
**Website:** https://mmudassir0.github.io/VidStash/

**Description:** Downloads YouTube videos, playlists and channels for offline viewing (up to 4K, M4A/MP3 audio, sections, chapter splitting, SponsorBlock), with a built-in player. Uses NewPipe Extractor on-device; no server, no accounts, no ads, no trackers.

**Metadata:** Fastlane metadata in `fastlane/metadata/android/` (en-US and ur): title, short/full description, icon, feature graphic, screenshots, changelogs named by versionCode.

**Release tags:** `v<versionName>` (e.g. `v1.2.60` = versionName 1.2.60, versionCode 160).

**Anti-features:** NonFreNet (YouTube). SponsorBlock data is CC BY-NC-SA and only used if the user turns it on.

**Self-updater:** The GitHub build can check GitHub for updates. Nothing is downloaded without the user tapping "Update" / "Download & install"; the prompt says the update comes from the GitHub page, and automatic checks can be switched off in Settings. A store build without the updater (`fdroid` flavour) exists if you prefer that one.
